# Reading Transformer Code: Resources

## Knowledge

- [PyTorch 2.11 Parameter](https://docs.pytorch.org/docs/2.11/generated/torch.nn.parameter.Parameter.html): registration with Module and default gradient tracking.
- [PyTorch 2.11 empty](https://docs.pytorch.org/docs/2.11/generated/torch.empty.html): uninitialized allocation; zero values are not guaranteed.
- [PyTorch 2.11 initialization](https://docs.pytorch.org/docs/2.11/nn.init.html#torch.nn.init.trunc_normal_): standard deviation and truncation bounds.
- [PyTorch 2.11 matmul](https://docs.pytorch.org/docs/2.11/generated/torch.matmul.html): matrix products and leading batch dimensions.
- [PyTorch 2.11 tensor transpose](https://docs.pytorch.org/docs/2.11/tensors.html#torch.Tensor.T): the two-dimensional transpose view.
- Local: `cs336_assignment1_basics.pdf`, Sections 3.3.1–3.3.2: required weight initialization and bias-free Linear interface.
- Local: `cs336_basics/Transformer.py`: the implementation under discussion. Installed PyTorch is 2.11.0+cu130.
