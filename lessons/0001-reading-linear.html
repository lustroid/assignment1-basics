From weight storage to output

Your goal: read the existing Linear implementation and predict one small forward pass. Quick reference

1. Allocate, register, initialize

self.weight = nn.Parameter(
    torch.empty(out_features, in_features, device=device, dtype=dtype)
)

empty allocates the requested shape without guaranteeing meaningful initial values. It does not zero-fill; zeros would. We immediately overwrite this storage with random weights, so zero-filling first would be redundant. PyTorch: empty.

Parameter identifies a model weight. Assigning it to self.weight makes it appear in the module's parameter collection, unlike an ordinary tensor attribute. Gradients default to enabled; the optimizer still performs the updates. This packages the role played by MicroGPT's manually collected parameter list. PyTorch: Parameter.

What does empty promise about its initial contents?

2. Set the initial scale

std = math.sqrt(2 / (in_features + out_features))
nn.init.trunc_normal_(self.weight, mean=0.0, std=std,
                      a=-3 * std, b=3 * std)

std means standard deviation: the spread of the underlying normal distribution. Section 3.3.1 specifies its variance as 2/(input width + output width); taking the square root gives std. Scaling initialization with layer width helps keep initial signals at a reasonable magnitude.

For 16 inputs and 16 outputs, std = √(2/32) = 0.25, and the permitted range is [−0.75, 0.75]. Truncation excludes the tails, so the final sample's measured standard deviation need not equal 0.25. The trailing underscore means the existing tensor is modified in place. PyTorch: truncated normal.

3. Compute one output per weight row

@ is Python matrix multiplication, not einops syntax. For tensors, it performs the matrix product. PyTorch: matmul.

x = [1  2  3]        weight = [1  0  1]
                              [0  1  1]

weight.T = [1  0]
           [0  1]
           [1  1]

For this 2D weight, .T swaps rows and columns through a view; it does not create another independent learned matrix. PyTorch: Tensor.T.

Each output is a dot product between x and one original weight row. This is the same operation performed by each row loop in MicroGPT's linear.

output 1 = 1×1 + 2×0 + 3×1
output 2 = 1×0 + 2×1 + 3×1

shapes: (1, 3) @ (3, 2) → (1, 2)

Calculate those two outputs.

With batches, the same weights act independently on each token: (batch, sequence, input width) → (batch, sequence, output width). Neither batch nor sequence length is mixed by this layer.
